⚠️ গুরুত্বপূর্ণ তথ্য

১. কোনও ক্লাব ডিলিট করার আগে স্বয়ংক্রিয়ভাবে একটি ব্যাকআপ তৈরি করা হয়।

২. ব্যাকআপ Restore করতে হলে মূল Club Owner-এর Auth Account সক্রিয় থাকতে হবে।

৩. মূল Club Slug যদি ইতিমধ্যে অন্য কোনও ক্লাব ব্যবহার করে থাকে, তাহলে নতুন একটি Slug দিতে হবে।

৪. JSON Backup ফাইলে গুরুত্বপূর্ণ ও সংবেদনশীল তথ্য থাকতে পারে, যেমন Streaming Configuration এবং Stream Key। তাই ডাউনলোড করা ব্যাকআপ ফাইল নিরাপদে সংরক্ষণ করুন।

৫. CSV Export-এ Streaming Configuration-এর stream_key গোপন রাখা হয়। সম্পূর্ণ তথ্যের জন্য সুরক্ষিত JSON Backup ব্যবহার করুন।

৬. Restore প্রক্রিয়া ব্যর্থ হলে ডেটাবেসে কিছু তথ্য আংশিকভাবে Restore হয়ে যেতে পারে। পুনরায় Restore করার আগে ডেটাবেস পরীক্ষা করে নিন।
